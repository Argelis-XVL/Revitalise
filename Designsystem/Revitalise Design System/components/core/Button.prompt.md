Solid pink pill CTA button, used for the site's primary actions ("Apply Now", "Donate Today").

```jsx
<Button variant="primary">Apply Now</Button>
<Button variant="secondary">Learn More</Button>
<Button variant="ghost">See all FAQs</Button>
```

Variants: `primary` (solid pink fill, white text — main CTAs), `secondary` (pink outline, transparent fill), `ghost` (underlined text link, no button chrome — used for lower-emphasis actions). Sizes: `sm`, `md` (default), `lg`.
