## Scope

When an application is created, check it against the charity's QuickBooks grant history and record the
outcome **on the application**:

- **FR-023** — check each new application against historical grant payment records at create time
  ([plan L1372](../../docs/plans/revitalise-grant-automation-plan.md#L1372)).
- **FR-024** — on a match, flag the application as a possible duplicate and record the prior grant's
  reference, date and amount ([plan L1373](../../docs/plans/revitalise-grant-automation-plan.md#L1373)).
- **FR-025** — on no match, record "no prior grants found" so the check is evidenced as having run
  ([plan L1374](../../docs/plans/revitalise-grant-automation-plan.md#L1374)).

Five columns on `rev_application`: `rev_duplicateflag`, `rev_priorgrantref`, `rev_priorgrantdate`,
`rev_priorgrantamount`, `rev_duplicatecheckedon`. Their field-security and form placement are part of
the order. The matching rules (which applicant details are compared, and how fuzzily) are **not** fixed
here; they depend on what QuickBooks can search (see *Re-price triggers*).

## Why this is a change order

Evidence: `contract/tad-deferrals.json` entry TD-007 (its `reason`), re-checked against `contract/wbs.json`:

- `wbs:7.2` matches on a **Payment** row created — holiday provider, holiday dates, grant reference —
  and flags a possible double-pay **on the Payment row** before issue. It does not run at application
  create, does not match on applicant identity, and writes nothing to `rev_application`.
- `wbs:4.3` / `wbs:4.4` (intake) do no QuickBooks lookup.
- No other task names these columns or an application-side duplicate flag.

The payment-side check (7.2) and this application-side check answer different questions at different
moments: *"is this payment a second payment?"* versus *"has this applicant been funded before we assess
them?"* (FR-023's stated purpose). The second is unquoted work (C-COM-002). Whether FR-023's parent
requirement sits under automation 7 is true, but the tasks beneath it do not deliver this half.
