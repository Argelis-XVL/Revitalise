## Scope

A round-level statistics landing screen in the trustee review portal
(`src/code-apps/trustee-review-portal/`), presenting aggregate application-round statistics as shown in
`docs/Import/Round 3 Stats.pptx` and `docs/Import/Round 4.pptx` (application counts, category/percentage
breakdowns, funding figures, demographic and circumstance-score distributions). Positioned in navigation
ahead of the existing applications list screen: landing → overview/list (`wbs:6.2`) → detail (`wbs:6.3`).

## Why this is a change order

No task in `contract/wbs.json` automation 6 (6.1–6.8) names a round-level aggregate screen. `wbs:6.1`
scopes "screens over the secured Application, Review and Grant tables" — record-level screens, spent
exactly by 6.2 (list) and 6.3 (detail), both of which already derive `complete` from evidence in
`contract/evidence-map.json`. WBS v0.5 is the customer-accepted Agreed Specification (D-5,
`docs/Import/baseline-lock.yml`); a task absent from it is unquoted work, not an ambiguity in an existing
task's wording.

straight filtered list. No comparable prior change order exists to size against (this is CO-001, the
first), and no evidence can bound hours for work not yet built. **The firm figure is deferred to
plan-agent's SDD** for `feature:trustee-portal-visual-refresh`, which has held this content out of its
committed scope pending this approval.

## Billing

Billable once delivered and evidenced against task id `6.9`, through the normal WBS-evidence path
(`scripts/deliverable-hours.py`) — not by this document. This change order makes `6.9` a covered id for
