## Scope

Four live gaps in the `rev_grantadministration` Grant Administration model-driven app, reported by
the reviewer and measured against the repository by `IMP-0785` / `IMP-0788`:

1. **An audit/reason field on the Casework tab** — a value a caseworker needs to see alongside
   `rev_status` is not currently surfaced there.
2. **An *Auto-pass Applications* saved view** (EF-16) plus a Casework sub-area beside the existing
   four views (`AllApplications`, `BorderlineAwaitingReview`, `UnderReviewIncompleteScoring`,
   `AutoRejectedApplications`) — confirmed absent at `IMP-0788` V1 (six `SavedQueries` files, none
   named Auto-pass).
3. **Gender/Equality views** — a caseworker-facing view over the *Equality Monitoring* section's
   gender and ethnic-group data (EF-19), confirmed absent at `IMP-0788` V1 (no saved query anywhere
   matched gender or equality).
4. **Wider columns on the Active Applications view** — confirmed at `IMP-0788` V1 that
   `ActiveApplications.xml` declared only five columns against what the reviewer expected to see.

`IMP-0785` originally logged a fifth candidate item, framed at the time as "trustee-portal-not
updated." `IMP-0788` corrected that framing: all of the reviewer's live observations are
`rev_grantadministration` components, not the trustee Code App. Neither `IMP-0785` nor `IMP-0788`
names what the fifth item's content actually is once separated from the trustee-portal
misattribution, and this dispatch has no independent source for it. **This document prices the four
items it can trace to a named, described gap. The possible fifth item is not priced here** — if the
reviewer confirms one still stands separately from items 1–4 above, it is a follow-on decision, not
a retroactive amendment to this figure.

## Why this is a change order, not in-scope build

`wbs:0.4`'s v0.6-corrected deliverable is "Dataverse solution + table schema + Grant Administration
app," and `wbs:2.2`'s is "Configured scoring columns + settings" (`contract/wbs.json`). Neither names
any of the four items above. `IMP-0785` records the check directly: none of the five accepted-WBS
deliverable texts touching `rev_grantadministration` names a Casework-tab audit field, an Auto-pass
view, a Gender/Equality view, or wider Active-applications columns. This is unquoted work under
C-COM-002 — a new WBS task, not rework against 0.4 or 2.2.

A development-agent dispatch began building against these gaps before this decision was raised,
attributed initially to `wbs:6.1`–`6.4` (the trustee Code App). `IMP-0788` disproved that
attribution: all four of those tasks' evidence rules correctly name `src/code-apps/trustee-review-
portal/` paths per ADR-003, and the live gaps are all `rev_grantadministration` (Model-Driven App)
components instead. The build work itself is not undone by that — this document exists to record
the decision the dispatch skipped, not to reopen already-shipped work.
